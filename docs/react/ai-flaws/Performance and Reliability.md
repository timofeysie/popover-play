Performance killers:
performance regressions, such as infinite API call loops, missing debouncing on search inputs, or failing to use optimization techniques like image lazy loading, code splitting, or table virtualization for large datasets.

Lack of context: 
Models focus on solving the immediate prompt without awareness of the system as a whole (e.g., fetching 100 items from an API when only 4 are displayed).

Missing resilience:
omit crucial resilience mechanisms like timeouts, retries, or proper error boundaries, which can cause system failures under real-world traffic.
